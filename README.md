# Dice Rolling Game

A browser-based dice game built as a JavaScript learning project with freeCodeCamp. Roll five dice, choose a scoring category, and try to earn the highest total over six rounds.

## How to Play

1. Open `index.html` in a browser.
2. Select **Roll the dice** to roll all five dice.
3. Choose an available scoring category, or roll again. You can roll up to three times each round.
4. Select **Keep the above selected score** to record your points and move to the next round.
5. Play all six rounds and try to beat your best score.

Use **Show rules** in the game to review the instructions while playing.

## Scoring

- **Three of a kind:** Sum of all five dice
- **Four of a kind:** Sum of all five dice
- **Full house:** 25 points
- **Small straight:** 30 points
- **Large straight:** 40 points
- **None of the above:** 0 points

## About the Project

This project was created as part of freeCodeCamp's [Review Algorithmic Thinking by Building a Dice Game](https://www.freecodecamp.org/learn/javascript-algorithms-and-data-structures-v8/review-algorithmic-thinking-by-building-a-dice-game/step-1) curriculum. It was an opportunity to practice JavaScript fundamentals, including arrays, loops, DOM updates, and game logic.
