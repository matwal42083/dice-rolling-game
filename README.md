# Dice Rolling Game

A browser-based dice rolling game built as a learning project while completing a freeCodeCamp assignment.

## About

The game uses HTML, CSS, and vanilla JavaScript to simulate a six-round dice game. Players can roll five dice up to three times per round, select an available scoring category, and track their total score.

## Features

- Roll five dice
- Score three-of-a-kind, four-of-a-kind, full house, small straight, and large straight
- Track rolls, rounds, score history, and total score
- View the game rules
- Responsive layout for smaller screens

## Run locally

Open `index.html` in a web browser, or use a local development server.
